# Email Generator ✉️

An AI-powered email generator that helps users quickly generate professional emails from prompts.  
This project includes a Spring Boot backend, frontend UI, and a Chrome extension.

---

## 🚀 Features

- Generate professional emails automatically
- Chrome extension integration
- Simple and clean UI
- Backend powered by Spring Boot
- Fast and lightweight

---

## 🛠 Tech Stack

### Backend
- Java
- Spring Boot

### Frontend
- HTML
- CSS
- JavaScript

### Extension
- Chrome Extension
